# Foodastry · Кулинарная книга в облаке

Статический сайт + бесплатное облако Supabase. Один раз настроили — и книга
открывается с любого устройства (компьютер, телефон, планшет) по одной ссылке:
без серверов, без установок, без учётных записей. Добавили рецепт с телефона —
он тут же виден на компьютере.

Аккаунтов нет намеренно: конфиденциальных данных в книге нет, доступ есть у всех,
у кого ссылка.

## Структура

| Файл | Что это |
|---|---|
| `index.html` | интерфейс книги |
| `app.js` | вся логика (маршруты, поиск, расчёт КБЖУ) |
| `db.js` | связь с облаком Supabase (чистый REST, без библиотек) |
| `config.js` | сюда вставляются настройки вашего Supabase-проекта |
| `supabase-setup.sql` | один SQL-скрипт, который создаёт таблицы в облаке |
| `style.css`, `*.woff2` | тема и шрифты (Nunito, Lora) |

## Настройка с нуля (≈10 минут)

### 1. Облако данных — Supabase (бесплатно)

1. Зайдите на [supabase.com](https://supabase.com) → **Start your project**.
2. **New project**: имя любое (например `foodastry`), пароль базы запоминать
   не нужно, регион — ближайший к вам (Frankfurt/Stockholm).
3. Слева **SQL Editor → New query**: вставьте весь текст `supabase-setup.sql` → **Run**.
4. **Project Settings (шестерёнка) → API** и перенесите в `config.js`:
   - **Project URL** → строка `window.SUPABASE_URL`
   - ключ **anon / public** → строка `window.SUPABASE_ANON_KEY`

### 2. Хостинг — GitHub Pages (бесплатно)

1. На [github.com](https://github.com) создайте репозиторий (например `foodastry`).
2. Через веб-интерфейс (**Add file → Upload files**) загрузите все файлы из этой
   папки: `index.html`, `app.js`, `db.js`, `config.js`, `supabase-setup.sql`,
   `style.css`, `README.md`, `LICENSE` и файлы шрифтов `*-600.woff2` / `*-400.woff2` / `*-700.woff2`.
3. Репозиторий → **Settings → Pages** → Branch: `main`, Folder: `/ (root)` → **Save**.
4. Через минуту книга откроется по адресу вида
   `https://ВАШ-НИК.github.io/foodastry/` — добавьте его в закладки на телефоне.

Обновления идут через Git: локально правим файлы → `beta.bat` → проверка
на бета-сайте → `release.bat`. Никакой ручной загрузки файлов через браузер.

## Как обновляться (ветки и бета-версия)

Сайт живёт в двух экземплярах, и оба бесплатны:

| Сайт | Ссылка | Репозиторий | Что это |
|---|---|---|---|
| **Основной** | `knclose.github.io/foodastry` | `knclose/foodastry`, ветка `main` | боевой — пользуются все |
| **Бета** | `knclose.github.io/foodastry-beta` | `knclose/foodastry-beta`, ветка `main` | черновик — смотрим сами |

Правки делаются локально в этой папке (ветка `dev`), а дальше два клика:

1. **`beta.bat`** — собрать и выкатить изменения на бета-сайт (спросит,
   что изменилось, — это подпись к обновлению). Через минуту проверяем
   на `foodastry-beta`, что всё в порядке.
2. **`release.bat`** — после проверки опубликовать то же самое на
   основном сайте. Всё, обновление уехало всем.

Если правка мелкая и очевидная, можно сразу `release.bat` без беты.

Рецепты и ингредиенты трогать не нужно — они живут в Supabase, а не в
репозитории. Подробности процесса: файл `workflow.md`.

## Ежедневная жизнь

- Открыли ссылку → работаем: поиск, «Рецепт дня», подсчёт КБЖУ — всё как было,
  только на любом устройстве.
- Данные хранятся в облаке: ваш компьютер может быть выключен, книга работает.
- Ингредиент, добавленный дома с компьютера, сразу доступен и на телефоне.

## Частые вопросы

**Ссылку кто-то увидит — страшно?** Нет — в книге нет личных данных. Любой,
у кого есть ссылка, сможет читать и добавлять рецепты.

**Сколько это стоит?** Ноль. GitHub Pages и бесплатный тариф Supabase не
требуют оплаты на объёмах семейной книги с большим запасом.

**Интернет нужен?** Да, книга теперь веб-сайт: без сети дизайн откроется,
но данные не подгрузятся.

**Как убрать доступ?** В Supabase переиздайте anon-ключ
(Settings → API → Regenerate) и замените его в `config.js`.
